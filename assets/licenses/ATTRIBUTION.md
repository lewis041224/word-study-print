# 词目与释义来源

- 义务教育词目：义务教育英语课程标准（2022年版），附录三级词汇表；小学按星号筛选。初高中课标与四六级大纲原表不提供中文释义。
- 高中词目：普通高中英语课程标准（2017年版2020年修订），附录2。原PDF镜像来自浙江师范大学。
- 四六级词目：全国大学英语四、六级考试大纲（2016年修订版），中国教育考试网原PDF。当前词目行数差异尚待核验，不能称已全面逐项验证。
- 精简英汉释义：现有3500条ECDICT精选，MIT，保留 assets/ECDICT-LICENSE。
- 考研词目、释义和其他书的补充释义：exam-data/NETEMVocabulary，2024英语一整理，提交70dc6b68c855f21e666a7a291ff8ead5ca1f7b44，https://github.com/exam-data/NETEMVocabulary 。数据 CC BY-NC-SA 4.0，须署名、仅限非商业、相同方式共享。代码MIT不代表数据MIT。含该补充释义的书JSON受此数据授权约束，商业使用需另取得授权。
- 所有释义为待核对建议；客户材料优先。词目来源文件SHA256、页码与原文行保存在各书JSON中。
